# Temafric website

Corporate website for **Temafric**, covering fuel, lubricants, steel, bitumen and mining supply, headquartered in Lubumbashi, DR Congo.

- Static HTML/CSS/JS, bilingual English/French with the EN | FR switch
- Pages: Home, About us, Services & products, References, Contact / Request a quote
- `quote.php` emails quote requests to sales@temafric.com (needs PHP hosting such as GoDaddy cPanel)
- Upload steps for GoDaddy: see `README.txt`
