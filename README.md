# Temafric website

Corporate website for **Temafric**, covering fuel, lubricants, steel, bitumen and mining supply, headquartered in Lubumbashi, DR Congo. Live address: **www.temafric.com**

- Static HTML/CSS/JS with no build step, bilingual English/French with the EN | FR switch
- Pages: Home, About us, Services & products, References, Contact / Request a quote
- The quote form sends requests to **sales@temafric.com** through FormSubmit (formsubmit.co), so it works on static hosting
- Hosted on **Vercel**, connected to this GitHub repository; the domain is registered at GoDaddy

Every change pushed to this repository is published to the live site automatically by Vercel.

See `DEPLOY.md` for the one-time setup steps.
